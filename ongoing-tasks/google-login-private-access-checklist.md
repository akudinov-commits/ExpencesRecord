# Google login and private access

## Goal
Enable Google sign-in/logout for the configured single user, protect backend functionality by default, and establish the approved server-side Google Sheets access mechanism for later mapping work. Feature execution was authorized on 2026-11-25. Step 01 is approved; implementation proceeds with delegated owner OAuth and seven-day database-free app sessions.

## Scope
- **In scope:** approve identity/session/CSRF/access design; application authorization and ports; infrastructure identity/session/credential mechanics; thin protected API and composition; sign-in/logout UI; controlled access verification and checked Preview handoff.
- **Out of scope:** workbook mapping, categories/currencies, formulas/FX, expense endpoints or writes, preferences, offline behavior, full PWA, reporting, paid resources and product production rollout. No production spreadsheet changes.
- **Dependencies:** [verified foundation](application-foundation-checklist.md), [roadmap](readme.md), [layer ADR](../adr/001-layer-boundaries.md), [Sheets ADR](../adr/002-sheets-authority-and-year-routing.md), [Accepted Google ADR](../adr/003-google-authentication-and-access.md), [hosting ADR](../adr/004-vercel-and-portability.md), [TDD ADR](../adr/006-tdd-and-feature-scope.md).
- **Decision gate:** the user selected delegated owner OAuth and explicitly approved seven-day database-free sessions with the explained logout limitation. ADR 003 is Accepted. Real Google owner verification, explicitly approved private credential storage, read-only refresh and the authorized isolated-workbook probe have passed. Hosted Preview setup, anonymous/security checks and real owner sign-in/logout are verified; no billing or trial is authorized.
