# 02 — Repository bootstrap — Configure project and architecture

## Goal
Configure project and architecture within the authorized documentation bootstrap.

## Track
Documentation / architecture

## What Exists
The approved product scope and FE/API/application/infrastructure separation are available in the conversation.

## What to Build
Configure the root README, architecture overview, active Node/React recipes and ADR index. Record accepted decisions and a Proposed Google-access ADR. Remove unused .NET/Python recipes and unrelated inherited tool permissions.

## Acceptance Criteria
- Architecture dependencies are explicit; no business logic is assigned to controllers or infrastructure; spreadsheet structure and formulas are protected.
- Verification evidence belongs in the checklist Notes, not in this specification.
