# 03 — Repository bootstrap — Enforce methodology

## Goal
Enforce methodology within the authorized documentation bootstrap.

## Track
Documentation / process

## What Exists

## What to Build
Align CLAUDE, its byte-identical Copilot mirror, AGENTS, ai-workflow, task/feature recipes, execution/session prompts and review rules with mandatory TDD and the simple-edit threshold. Normalize instructional marker examples outside preserved templates.

## Acceptance Criteria
- Behavior changes require observed RED before implementation and recorded GREEN; nontrivial work has a named feature; documentation-only verification is clearly distinguished.
- Verification evidence belongs in the checklist Notes, not in this specification.
