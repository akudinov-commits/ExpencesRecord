# 01 — Repository bootstrap — Capture discovery and approved decisions

## Goal
Capture discovery and approved decisions within the authorized documentation bootstrap.

## Track
Documentation

## What Exists
The repository contains a generic context-driven development template and no application manifests.

## What to Build
Write factual discovery and approved decisions under ongoing-tasks/_bootstrap/. Distinguish accepted architecture from proposals and deferred toolchain choices.

## Acceptance Criteria
- Inputs reflect the conversation; no installed dependencies, credentials or approved authentication mechanism are invented.
- Verification evidence belongs in the checklist Notes, not in this specification.
